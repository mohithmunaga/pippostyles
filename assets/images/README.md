# Gallery Images Directory

Place your custom creator/influencer images in this folder or in `../r2/`.

### How to use in `src/data.js`:
Set the `image` or `imageSmall` path for any card:
```javascript
{
  id: 399,
  title: "Influencer Name",
  image: "/assets/images/influencer-01.jpg",
  imageSmall: "/assets/images/influencer-01.jpg",
  // ...
}
```

The 3D cards, ring, spiral, curvature, and animations will automatically inherit your image!
